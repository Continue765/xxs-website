规则说明

参赛前

  • 正式选手请携带组委会认可的身份证明，按公布时间报到。
  • 请提前熟悉评测系统、允许使用的语言与机房开发环境。
  • 个人座位及账号由组委会通过选手群或现场材料发放，本站不公开联系方式和密码。

赛制说明

本届赛制待公布。若采用 ACM 赛制，请在发布前核对排名、罚时、封榜和编译错误是否计罚等规则与实际 OJ 配置。

赛场纪律

  • 按座位安排使用比赛用机；设备异常请联系工作人员。
  • 禁止代打、与其他选手交流答案及使用未经允许的外部辅助工具。
  • 纸质资料、上网、生成式 AI、提前离场等具体规定，请组委会确认后在这里补齐。

异常与更正

发现题意、评测或设备问题，请通过现场工作人员或 OJ 提问渠道反馈。统一更正和时间调整以组委会通知为准。

奖项与环境

  • 金牌：排名第一的正式参赛选手
  • 银牌：排名第二的正式参赛选手
  • 铜牌：排名第三的正式参赛选手
  • 一等奖：正式参赛选手中，排名占有效参赛人数比例在 (0%, 10%] 的选手
  • 二等奖：正式参赛选手中，排名占有效参赛人数比例在 (10%, 30%] 的选手
  • 三等奖：正式参赛选手中，排名占有效参赛人数比例在 (30%, 60%] 的选手
  • 最快解题奖：正式参赛选手中，每题最快正确解出的选手

比赛环境

  • 甲：系统环境甲（对四种语言均有需求，或对 Visual Studio Code 有需求）：Dev-C++ 5.11 (gcc 4.9.2, g++ 4.9.2)、Python 3.8.6、Python 3.12.2、Eclipse IDE for Java Developers 4.16.0 (JavaSE-14)、Visual Studio Code 1.87.2。Visual Studio Code 未配置 C/C++ 和 Java 开发环境。（C, C++, Java, Python 3）
  • 乙：系统环境乙（对 C/C++ 或 Python 有强需求）：Dev-C++ 5.10 (gcc 4.8.1, g++ 4.8.1)、Code::Blocks 20.03 (gcc 8.1.0)、PyCharm 2021.3.3 (Community Edition)、Python 3.9.7。（C, C++, Python 3）
  • 丙：系统环境丙（对 Java 或 Python 有强需求，对 C/C++ 有弱需求）：Code::Blocks 20.03 (gcc 8.1.0)、PyCharm 2020.1 (Professional Edition)、Python 3.12.2、IntelliJ IDEA 2021.3 (OpenJDK 11.0.12)、Eclipse IDE for Java Developers 4.22.0 (JavaSE-17)。（C, C++, Java, Python 3）
